# Локальный запуск проекта

Инструкция для проверяющего: как поднять проект у себя на машине и что нужно,
чтобы увидеть работающий чат.

## Требования

- Node.js `^20.19.0` или `>=22.12.0`
- npm

Проверено на Node.js 24.21.0 и npm 11.19.0.

Проверить версии:

```bash
node -v
npm -v
```

## Запуск

```bash
git clone <ссылка на репозиторий>
cd <имя репозитория>
npm install
npm run dev
```

Приложение откроется на http://localhost:5173

## Два режима работы

### Демо-режим

Ничего настраивать не нужно. На экране входа нажмите **«Открыть демо-режим»**.

Собеседник отвечает локально, запросов в сеть не уходит. Достаточно:

1. нажать **«Новый чат»**;
2. ввести любой номер в формате `79991234567` (11 цифр для РФ) или `375291234567` (12 цифр для РБ);
3. написать сообщение — через пару секунд придёт ответ, галочки доставки сменятся на «прочитано».

### Режим GREEN-API

Нужен аккаунт на [console.green-api.com](https://console.green-api.com):

1. Создайте инстанс и авторизуйте его в MAX — QR-код или вход по номеру телефона.
2. Убедитесь, что поле **webhookUrl** в настройках инстанса **пустое**. Если там есть адрес, GREEN-API работает в режиме webhook и уведомления нельзя будет забрать через HTTP API. Приложение умеет чистить это поле само — галочка на экране входа вызывает `SetSettings`.
3. Скопируйте `idInstance` и `apiTokenInstance` из личного кабинета.
4. Вставьте их на экране входа и нажмите **«Войти»**. Галочку «Включить получение уведомлений» оставьте включённой.
5. Нажмите **«Новый чат»**, введите номер телефона в MAX — приложение вызовет `CheckAccount`, получит `chatId` и откроет чат.
6. Пишите сообщения. Входящие появятся в ленте автоматически: приложение висит на `ReceiveNotification` с таймаутом 25 секунд.

Если инстанс не авторизован, экран входа покажет его состояние — `notAuthorized`, `starting`, `deleted` или `suspended`.

Учётные данные сохраняются в `localStorage` браузера, перезагрузка страницы их не сбрасывает. Кнопка выхода в шапке удаляет их.

## Скрипты

| Команда | Что делает |
| --- | --- |
| `npm run dev` | dev-сервер с hot reload на порту 5173 |
| `npm run build` | проверка типов и production-сборка в `dist/` |
| `npm run preview` | локальный просмотр собранной версии |
| `npm run typecheck` | только проверка типов, без сборки |

## Онлайн-версия

Проект опубликован через GitHub Pages, поэтому в нём работает только демо-режим:
живой режим требует, чтобы запросы к `api.green-api.com` проходили CORS-проверку
браузера, а на статическом хостинге это гарантировать нельзя.

## Если что-то пошло не так

**Порт 5173 уже занят**

```bash
npm run dev -- --port 5174
```

**Ошибки при установке зависимостей**

```bash
rm -rf node_modules
npm ci
```

`npm ci` устанавливает точные версии из `package-lock.json` — так воспроизводится
точно то же окружение, что и у разработчика.

**Сообщения отправляются, ответы не приходят**

- инстанс должен быть авторизован в MAX;
- `webhookUrl` должен быть пустым;
- посмотрите индикатор в шапке чата: серый — ожидание, зелёный — получение
  уведомлений активно, красный — связь потеряна.

**`CORS` в консоли браузера**

Запрос к `api.green-api.com` заблокирован браузером. Для live-режима понадобится
прокси на бэкенде. Демо-режим при этом работает как обычно — сетевых запросов
в нём нет.

**`ERR_PNPM_OUTDATED_LOCKFILE` или ошибки версий**

Проверьте версию Node.js: `node -v`. Нужен `^20.19.0` или `>=22.12.0`.
